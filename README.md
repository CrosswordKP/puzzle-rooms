## กระดานภารกิจ

ความคืบหน้าส่งไปที่ Google Sheet "กระดานภารกิจ ห้องปริศนา (ว21105)" ในบัญชีของครู (แผ่นงาน log) ผ่าน Apps Script (`Code.gs`) ข้อมูลมีเฉพาะ ชุดรหัส ทีม บทบาท ด่าน จำนวนข้อที่เสร็จ จำนวนครั้งที่ตอบผิด และรหัสเครื่องแบบสุ่ม ไม่มีชื่อนักเรียน

ก่อนเริ่มแต่ละคาบ กด "เริ่มคาบใหม่" 2 ครั้งที่หน้าตู้เวลา

## เสียง

- มือถือ : เอฟเฟกต์สั้น ๆ ตอนตอบถูก ตอบผิด ผ่านด่าน ได้อักษร ปุ่ม "เสียง: เปิด/ปิด" มุมขวาบน
- จอทีวี : ปุ่ม "ดนตรี" (ดนตรีประกอบวนต่อเนื่องทุกหน้าจอทีวี) และ "เสียง" (นับถอยหลัง เฉลย ทีมเปิดตู้เวลา มีคนได้อักษร)
- เสียงทั้งหมดสังเคราะห์ในโค้ด ไม่มีไฟล์เพลง ไม่มีปัญหาลิขสิทธิ์ เบราว์เซอร์จะเริ่มเล่นเสียงหลังแตะหน้าจอครั้งแรก
