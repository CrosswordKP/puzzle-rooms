## วิธีขึ้น GitHub Pages (ทำผ่านเว็บ ไม่ต้องใช้โปรแกรม)

1. เข้า github.com แล้วล็อกอิน
2. มุมขวาบนกด **+** → **New repository** ตั้งชื่อ `puzzle-rooms` เลือก **Public** แล้วกด **Create repository**
3. ในหน้าที่ขึ้นมา กดลิงก์ **uploading an existing file**
4. ลากไฟล์ `index.html` (และ `README.md`) จากโฟลเดอร์นี้ลงไป แล้วกด **Commit changes**
5. ไปที่ **Settings** → **Pages** ช่อง **Branch** เลือก `main` และ `/ (root)` แล้วกด **Save**
6. รอ 1–2 นาที รีเฟรชหน้า Pages จะเห็นลิงก์ `https://<ชื่อผู้ใช้>.github.io/puzzle-rooms/`

ส่งลิงก์นี้กลับมา แล้วจะทำ QR ของจริงใส่หลังการ์ดบทบาทให้

## หมายเหตุ

- รหัสตู้เวลาคืออักษรของห้อง 1–5 เรียงกัน (ครูทดสอบได้โดยเล่นครบ 5 ห้อง)
- ความคืบหน้าและรายการทีมที่เปิดตู้เวลาเก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ไม่ส่งข้อมูลนักเรียนออกไปที่ใด
- ก่อนเริ่มคาบใหม่ ที่หน้าตู้เวลา กด “ล้างรายการ” สองครั้ง
- ไฟล์ `.nojekyll` ให้ GitHub แสดงไฟล์ตามที่เป็น (ถ้าอัปโหลดผ่านเว็บไม่ได้ ข้ามได้ ไม่กระทบเกม)
