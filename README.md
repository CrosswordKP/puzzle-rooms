## กระดานภารกิจ

ความคืบหน้าส่งไปที่ Google Sheet "กระดานภารกิจ ห้องปริศนา (ว21105)" ในบัญชีของครู (แผ่นงาน log) ผ่าน Apps Script (`Code.gs`) ข้อมูลมีเฉพาะ ชุดรหัส ทีม บทบาท ด่าน จำนวนข้อที่เสร็จ จำนวนครั้งที่ตอบผิด และรหัสเครื่องแบบสุ่ม ไม่มีชื่อนักเรียน

ก่อนเริ่มแต่ละคาบ กด "เริ่มคาบใหม่" 2 ครั้งที่หน้าตู้เวลา
